# Magic+

Русскоязычный плагин магии для **Paper 1.18.2**. У каждого игрока есть личный запас маны, автоматическое восстановление и постоянно обновляемая полоска в action bar. Заклинания разделены по классам, а баланс полностью настраивается через YAML-файлы.

## Возможности

- персональная мана и персональный максимум маны;
- автоматическое восстановление маны;
- настраиваемая полоска маны над хотбаром;
- волшебный жезл: **ЛКМ** переключает заклинание, **ПКМ** применяет его;
- сохранение маны, максимума, выбранного заклинания и первого получения жезла в `players.yml`;
- права доступа на каждое заклинание;
- кулдауны, стоимость, радиус, сила и длительность настраиваются в `config.yml`;
- все пользовательские сообщения вынесены в `messages.yml` и написаны на русском;
- автодополнение команд;
- безопасная перезагрузка настроек командой `/magic reload`.

## Встроенные заклинания

| ID | Название | Действие |
|---|---|---|
| `healing` | Исцеление | Лечит существо перед игроком или самого мага |
| `cleansing` | Очищение | Снимает яд, иссушение, слабость, замедление и другие негативные эффекты |
| `fireball` | Огненный шар | Запускает малый огненный шар по направлению взгляда |
| `poison` | Ядовитое касание | Накладывает отравление на выбранное существо |
| `weakness` | Печать слабости | Накладывает слабость и замедление |
| `drain` | Похищение жизни | Наносит урон цели и лечит мага |

Для направленных заклинаний нужно смотреть на живое существо. В команде `/magic cast` игрока также можно указать по нику.

## Установка

1. Установите сервер **Paper 1.18.2** с **Java 17**.
2. Соберите проект или скачайте готовый `MagicPlus-1.0.0.jar`.
3. Поместите JAR в папку `plugins` сервера.
4. Перезапустите сервер.
5. Измените `plugins/MagicPlus/config.yml` при необходимости и выполните `/magic reload`.

## Сборка

Требуются JDK 17 и Maven 3.8+:

```bash
mvn clean package
```

Готовый файл появится по пути `target/MagicPlus-1.0.0.jar`.

## Команды

| Команда | Описание |
|---|---|
| `/magic help` | Справка |
| `/magic mana` | Показать свою ману |
| `/magic spells` | Показать доступные заклинания, стоимость и кулдаун |
| `/magic select <id>` | Выбрать заклинание |
| `/magic cast <id> [игрок]` | Применить заклинание |
| `/magic wand` | Получить волшебный жезл |
| `/magic mana <игрок>` | Посмотреть ману игрока (администратор) |
| `/magic wand [игрок]` | Выдать жезл (администратор) |
| `/magic setmana <игрок> <число>` | Установить текущую ману |
| `/magic addmana <игрок> <число>` | Добавить ману |
| `/magic setmax <игрок> <число>` | Установить персональный максимум |
| `/magic reload` | Перезагрузить `config.yml` и `messages.yml` |

Алиасы главной команды: `/magicplus`, `/mag`.

## Права

| Право | По умолчанию | Описание |
|---|---|---|
| `magicplus.use` | всем | Основные команды |
| `magicplus.wand` | всем | Использование жезла |
| `magicplus.spell.*` | всем | Все встроенные заклинания |
| `magicplus.spell.<id>` | через `spell.*` | Отдельное заклинание, например `magicplus.spell.poison` |
| `magicplus.admin` | OP | Перезагрузка, выдача и изменение маны |

## Структура проекта

```text
src/main/java/ru/magicplus/
├── MagicPlusPlugin.java       # жизненный цикл плагина
├── command/                   # команды и автодополнение
├── config/                    # сообщения
├── listener/                  # вход/выход и использование жезла
├── mana/                      # профиль и хранение маны
├── spell/                     # API, реестр и реализация заклинаний
│   └── impl/                  # отдельный класс на каждое заклинание
├── task/                      # регенерация и action bar
├── util/                      # цвета и поиск цели
└── wand/                      # создание и выдача жезла
```

### Добавление нового заклинания

1. Создайте класс в `spell/impl`, унаследованный от `AbstractSpell`.
2. Добавьте его секцию в `config.yml`.
3. Зарегистрируйте класс в `SpellManager#reload()`.
4. Добавьте право `magicplus.spell.<id>` в `plugin.yml` и сообщения в `messages.yml`.

## Конфигурационные файлы

- `config.yml` — мана, регенерация, action bar, жезл и баланс заклинаний;
- `messages.yml` — весь русский текст и цветовое оформление;
- `players.yml` — создаётся автоматически, хранит данные игроков; вручную редактировать его при запущенном сервере не рекомендуется.

Цвета задаются стандартными кодами Minecraft через `&`, например `&d` или `&l`.
